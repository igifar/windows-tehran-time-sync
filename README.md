# تنظیم منطقه زمانی تهران و همگام‌سازی ساعت ویندوز

این پروژه شامل یک فایل اجرایی Batch با پسوند BAT است که برای تنظیم خودکار منطقه زمانی ویندوز روی تهران و رفع مشکلات همگام‌سازی ساعت سیستم طراحی شده است.

این اسکریپت تلاش می‌کند ساعت ویندوز را با استفاده از سرورهای زمان (NTP) همگام‌سازی کند و در صورت عدم موفقیت، از روش جایگزین HTTPS استفاده کند.

## امکانات

- تنظیم خودکار منطقه زمانی ویندوز روی تهران
- درخواست دسترسی مدیر سیستم در صورت نیاز
- راه‌اندازی و آماده‌سازی سرویس Windows Time
- تلاش برای همگام‌سازی ساعت با سرورهای NTP ایران
- استفاده از سرورهای جایگزین آسیایی و بین‌المللی در صورت عدم موفقیت
- استفاده از روش HTTPS به‌عنوان راهکار جایگزین
- نمایش نتیجه عملیات و وضعیت همگام‌سازی ساعت

## پیش‌نیازها

- ویندوز ۱۰ یا ۱۱
- اتصال به اینترنت
- دسترسی مدیر سیستم (Administrator)
- فعال بودن PowerShell در ویندوز

## نحوه استفاده

۱. فایل `Set-Tehran-Timezone-fixed.bat` را دانلود کنید.

۲. روی فایل دوبار کلیک کنید.

۳. در صورت نمایش پنجره تأیید دسترسی مدیر سیستم، گزینه Yes را انتخاب کنید.

۴. منتظر بمانید تا عملیات تنظیم منطقه زمانی و همگام‌سازی ساعت انجام شود.

۵. نتیجه عملیات را در پنجره اجرا مشاهده کنید.

## نکات مهم

- اجرای این فایل باعث تغییر منطقه زمانی و برخی تنظیمات سرویس زمان ویندوز می‌شود.
- برای استفاده از سرورهای NTP، ارتباط اینترنتی و امکان دسترسی به پورت UDP شماره ۱۲۳ لازم است.
- روش HTTPS صرفاً در صورت شکست روش‌های همگام‌سازی NTP استفاده می‌شود.
- اگر ساعت سیستم پس از خاموش و روشن شدن مجدداً به‌هم می‌ریزد، احتمال خرابی باتری CMOS مادربرد وجود دارد.
- توصیه می‌شود پیش از اجرا، محتوای فایل BAT را بررسی کنید.

## دریافت فایل

فایل اجرایی این پروژه با نام زیر در مخزن قرار دارد:

`Set-Tehran-Timezone-fixed.bat`
